# Visual Eyez Media — Website

## Overview

This repository contains the official website for **Visual Eyez Media**, a full-service creative agency specializing in design, development, and brand identity. The site is built as a modern, single-page experience focused on strong visual presentation, smooth user interaction, and clear service offerings.

The design emphasizes a sleek, high-end aesthetic using a dark UI, refined typography, and subtle motion effects to create an engaging and immersive browsing experience.

---

## Features

* **Responsive Layout** — Optimized for desktop, tablet, and mobile devices
* **Modern UI/UX Design** — Clean structure with elegant typography and spacing
* **Hero Section** — Strong branding with animated entrance effects
* **Service Showcase** — Clearly defined offerings with structured layouts
* **Pricing & Packages** — Interactive sections for easy comparison
* **Contact Form** — Built-in form for client inquiries
* **Smooth Scrolling & Animations** — Enhanced user experience with subtle transitions
* **Custom Styling** — Fully styled using CSS (no external frameworks)

---

## Technologies Used

* **HTML5** — Semantic and structured markup
* **CSS3** — Custom styling, layout, and animations
* **Google Fonts** — Typography (Montserrat, Playfair Display, Cormorant Garamond)
